## AI Interview Body Language Coach

Overview:
The AI Interview Body Language Coach is a web-based application that helps users improve their non-verbal communication during interviews. It provides real-time feedback on posture, gestures, and facial expressions using computer vision.

Technologies Used: HTML, CSS, JavaScript | MediaPipe (Pose, Hands, Face Mesh) | Chart.js | Node.js (backend concept)

Features: Real-time webcam analysis, Posture detection (slouching, uneven shoulders, head position), Gesture recognition (open palm, fist, movement detection), Facial expression analysis (confidence, stress, attentiveness), Timed interview questions, Performance summary using charts

Improvements (Latest Version): Enhanced posture detection accuracy, Improved gesture recognition logic, Better facial expression classification, Cleaner UI and feedback system

How to Run:
1. Download or clone the repository
2. Open `index.html` in a browser
3. Allow camera access
4. Start the interview session

Future Enhancements: Speech analysis, AI-based suggestions, YOLO-based object/environment detection
